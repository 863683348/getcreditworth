## 一、Product Hunt

**提交地址**：[https://www.producthunt.com/posts/new](https://www.producthunt.com/posts/new)

### 前置准备
- 准备 3 张截图（首页排行榜 / 书籍详情 / 计算器页面），1280x800 或 16:9 比例
- 准备 favicon 或 512x512 logo

### 操作步骤

1. 用 GitHub 或 Google 账号登录 Product Hunt
2. 右上角头像 -> **Submit a Product**
3. 填写字段：

| 字段 | 内容 |
|------|------|
| Product Name | `GetCreditWorth` |
| Tagline（一句话标语） | `Data-driven tool to maximize your Audible credit value — ranks audiobooks by hours × rating ÷ price` |
| Description | `Compare 300+ audiobooks by Value Score, cost per hour, and credit worth. Find the best books to spend your monthly credits on.` |
| Website URL | `https://getcreditworth.com` |
| Icon | 上传 favicon / logo |
| Gallery Images | 上传 3 张截图 |
| Topics | 添加 `Audio Books`、`Productivity`、`Data Driven` |

4. 提交后等待审核，产品页本身会被 Google 收录

### 第一条评论（Maker 视角）

建议在提交后立即发一条评论：

> As an Audible Premium Plus member, I kept feeling like I was gambling my monthly credit. A 6-hour book and a 45-hour book both cost exactly one credit — but one is clearly a better deal.
>
> So I built GetCreditWorth.
>
> It ranks 300+ audiobooks by a **Value Score** — a simple formula: (hours × rating) ÷ price. The higher the score, the more listening value you get per credit. Plus cost-per-hour, credit ROI, and an adjusted score weighted by review count to avoid the "3 reviews = 5 stars" trap.
>
> A few things I'm proud of:
> - **Bilingual (EN/ZH)** — didn't want to leave Chinese-speaking Audible users out
> - **Card + Table views** — inspired by diskprices.com, because sometimes you want visual, sometimes you want dense data
> - **Real cover images** — a painful lesson in how Audible ASINs ≠ Amazon ASINs, but finally got all 300 books with covers
> - **A credit calculator** for when you want to decide between paying cash vs. using a credit
>
> I'd love your feedback — especially if you have a favorite audiobook that should be on the list but isn't yet.
>
> 👉 **https://getcreditworth.com**

## 二、BetaList（已确认免费）

**提交地址**：[https://betalist.com/submit](https://betalist.com/submit)
**费用**：免费（当初提交即可，无需付费）

### 操作步骤

1. 用 Google 账号或邮箱注册登录
2. 点击 **Submit Your Startup**
3. 填写字段：

| 字段 | 内容 |
|------|------|
| Product Name | `GetCreditWorth` |
| Tagline | `Maximize your Audible credit value with data-driven rankings` |
| Description（100-500字） | 参考下方模板 |
| Website | `https://getcreditworth.com` |
| Product Stage | 选 `Launched` |
| Logo | 上传 512x512 图标或 favicon |

### Description 模板

> Audible members get 1-2 credits per month, but choosing which book to spend them on is a guessing game. A $5 short story and a $50 epic novel both cost exactly one credit — but their value is wildly different.
>
> GetCreditWorth solves this with a data-driven Value Score: (hours × rating) ÷ price. The higher the score, the more listening value you get per credit.
>
> Key features:
> - 300+ audiobooks ranked by Value Score
> - Filter by duration, rating, and category
> - Card view for visual browsing, Table view for data-heavy scanning
> - Book detail pages with full value breakdown
> - Credit calculator — decide whether to use a credit or pay cash
> - Amazon Affiliate redirects
> - Built with Next.js 14 SSG + ISR, TypeScript, Tailwind CSS
>
> Bilingual support: English and Chinese.

4. 提交后 1-3 天审核通过

### Description 模板

### Description 模板
