## 核心要点

### 1. 核心价值算法（Value Score）
```
Value Score = (时长_hours x 评分) / 价格_USD
```

- 设计逻辑：积分等价交换，长篇幅 = 更低每小时成本，价格越高用积分越划算
- 辅助指标：Cost per Hour、Credit Worth（积分 ROI 倍数）、Adjusted Value（用评论数 log 加权防刷分）

### 2. 数据规模
- **静态页面**：331 个（首页、排行榜、300+ 书籍详情、4 个精选手册、10 篇博客、计算器、关于页等）

## 数据流设计

采用无数据库的纯静态方案：

```
SSG/ISR 构建时: page.tsx (Server) -> controller -> data layer (JSON 文件)
运行时交互:   Client Component -> apiClient -> /api/* -> controller -> data layer
```

- **数据源**：Amazon PA-API 5.0（300 本书数据）
- **数据更新**：每日凌晨 3:00 UTC Cron 拉取最新价格/评分 -> 写入 books.json -> Git push -> Vercel 自动构建
- **ISR 策略**：首页 revalidate=3600s（1h），列表页 86400s（24h），详情页 604800s（7d）
