# GetCreditWorth 外链冷启动策略

> 当前状态：刚刚上线，300 本书数据，330+ 页面，中英双语，GA4 已接入
> 目标：用 3 个月把自然搜索流量从 0 拉到千级 UV/月

---

## 现状分析

### 优势
- **工具体验好**：330+ 页面 SSG + 响应式 + 双语，Value Score 算法独有，竞品只有 226 本书且设计老旧
- **数据真实**：300 本书封面图、ASIN、价格/评分已验证，Affiliate 链路已通
- **SEO 基础打完**：Sitemap、robots.txt、结构化数据（JSON-LD）、OG 图、GA4 均已就位
- **域名品牌化**：getcreditworth.com，.com TLD，名称自带关键词（credit + worth）

### 短板
- **内容量为零**：博客目前只有 3 篇文章，搜索不到有价值的内容去让人引用
- **无社交媒体存在**：没有任何社交账号矩阵，别人无法"顺藤摸瓜"发现你
- **零外链**：新域名，DA = 0，Google 发现+信任需要时间
- **功能未覆盖中文分词**：中文版虽已接入，但中文 SEO 的 H1/H2 关键词密度未专门优化

## 分步执行计划

### 第 1 天：Product Hunt 提交
1. 注册/登录 Product Hunt
2. 提交产品
3. 使用上述英文模板发第一条 Maker 评论
4. 分享到 Twitter/LinkedIn

### 第 1 周：社区种草
1. **Reddit**：注册账号，先在 r/audible 回答问题（不直接发链接），建立账号权重
2. **Quora**：回答 5 个高流量问题
3. **BetaList**：提交工具
4. **AlternativeTo + SaaSHub**：提交并标记为竞品替代品
5. **Hacker News**：提交 Show HN

### 第 2 周：内容矩阵启动
1. 发布第 2 批 3 篇博客
2. Reddit 发第一篇带链接的内容帖
3. 用 Google dork 扫描资源页面，每天 outreach 5 个站长

### 第 3-4 周：规模扩张
1. 继续博客内容生产（每周 3 篇）
2. 失效链接替换 outreach
3. 制作信息图 + 数据开放集
